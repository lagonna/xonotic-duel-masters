# Duel Masters — Xonotic Community Tournaments Website

This is the source code behind **[duelmasters.gamer.gd](https://duelmasters.gamer.gd)** — a free, community-run tournament website built by fans, for fans.

We publish our code openly so the community can see exactly how the platform works, report issues, and contribute improvements.

---

## Want to play? Head to the website

**[duelmasters.gamer.gd](https://duelmasters.gamer.gd)**

This repo is just the code. To join or create tournaments, create an account, or hang out — go to the site.

---

## Found a bug? Have an idea?

Open an [issue](https://github.com/VantaTomat/xonotic-duel-masters/issues) and let us know. This platform is built around the community — your feedback actually matters.

---

## Want to contribute?

You don't have to be a developer to help. You can:

- **Report bugs** — something broke? Tell us
- **Suggest features** — open an issue with your idea
- **Submit a PR** — if you can code, fixes and improvements are welcome

Keep changes focused. Don't try to make it commercial — this is and will always stay a free fan project.

---

## Tech Stack

Backend: PHP & MySQL (Robust, server-side logic)

Frontend: Vanilla JavaScript (Fast, framework-less UI)

Philosophy: Zero dependencies for maximum transparency.
